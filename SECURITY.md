# Security policy

## Supported versions

Only the latest commit on `main` is supported. This is a portfolio project, not a hosted product.

## Reporting a vulnerability

Please report problems privately, not in a public issue.

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability** and describe the problem, the steps to reproduce it, and the impact.

I will reply within 7 days, and I will credit you in the fix if you want.

## Known limitations

Some weaknesses are already known and written down in the README ("Assumptions, shortcuts, and
trade-offs"). You do not need to report those.
